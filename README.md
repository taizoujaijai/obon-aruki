# おぼん歩き

スマホをお盆に見立てて、上に載ったものを落とさず・こぼさずに20歩あるくバランスゲームです。スマホのブラウザだけで遊べます。

**▶ 遊ぶ：https://taizoujaijai.github.io/obon-aruki/**

## 遊び方

1. スマホで上のURLを開き、難易度を選んで「はじめる」を押します。
2. 画面を上に向けて、お盆のように水平に持ちます。3秒間、そのままの持ち方を「水平」として記録します。
3. スマホを傾けないように気をつけながら歩きます。20歩あるけたらクリアです。

次のどちらかになるとゲームオーバーです。

- ボールやコップがお盆の縁から落ちる
- コップの水がこぼれすぎる（「こぼれた水」のゲージが満タンになる）

| 難易度 | お盆に載っているもの |
|---|---|
| かんたん | ボール1つ |
| ふつう | 水の入ったコップ、ボール1つ |
| むずかしい | 水の入ったコップ2つ、ボール3つ |

## 動作環境

- 傾きセンサーと加速度センサーがあるスマホ（iPhone / Android）
- iPhoneでは「はじめる」を押したときに出るダイアログで、モーションセンサーの使用を「許可」してください。
- 画面の回転はロックしておくと安定します。

PCではタイトル画面の「PCで試す」から遊べます。ドラッグで傾け、スペースキーで1歩進みます。

## 仕組み

`index.html` 1ファイルだけで動いています。外部のライブラリは使っていません。

- **傾き**：`DeviceOrientationEvent` で取得します。歩くときの細かい揺れは平滑化し、小さな傾きは無視します。
- **歩数**：`DeviceMotionEvent` の加速度から、上下の揺れのピークを1歩として数えます。
- **物理**：ボールは転がり、コップは摩擦で止まり、コップの水面はばねのように揺れます。

難しさや歩数検出の感度は、`index.html` のスクリプト冒頭にある `DIFF` と `STEP_HI` などの値で調整できます。

## 注意

- センサーはHTTPSのページでしか動きません。ローカルでファイルを直接開いた場合は「PCで試す」だけが使えます。
- 歩数は加速度から推定しているので、数歩ずれることがあります。その場でスマホを上下に振っても歩数が増えます。
- 歩きながら遊ぶときは、周りや足元に気をつけてください。
