# おぼん歩き

スマホをお盆に見立てて、載せたものを落とさず・こぼさず・倒さずに10歩あるくバランスゲームです。スマホのブラウザだけで遊べます。

**▶ 遊ぶ：https://taizoujaijai.github.io/obon-aruki/**

## 遊び方

1. スマホで上のURLを開き、お盆に載せるものを選んで「はじめる」を押します。
2. 画面を上に向けて、お盆のように水平に持ちます。3秒間、そのままの持ち方を「水平」として記録します。
3. スマホを傾けないように気をつけながら歩きます。10歩あるけたらクリアです。

## 載せるもの

| 載せるもの | こうなったらゲームオーバー |
|---|---|
| ボール1個 / 5個 / 10個 | 転がってお盆から落ちる |
| 本20冊 | 積んだ本が崩れる |
| 水たっぷりのコップ | 水がこぼれる |
| ワイン入りのワイングラス | ワインがこぼれる、グラスが倒れる |
| シャンパンタワー | シャンパンがこぼれる、タワーが崩れる |
| パンケーキタワー | タワーが倒れる |
| トランプのピラミッド | ピラミッドが崩れる |
| 学校給食 | みそ汁がこぼれる、牛乳びんが倒れる |
| 沸騰したお湯の鍋 | 熱湯がこぼれる（何もしなくても沸騰で揺れます） |
| 熱々おでんのお椀3個 | つゆがこぼれる |
| 立っている鉛筆5本 | 1本でも倒れる |
| 眠っている猫 | 傾けすぎて猫が起きる |

どれも、お盆の縁から落ちた時点でゲームオーバーです。画面右上の「あぶない度」で、こぼれたり倒れたりする寸前かどうかがわかります。

## 動作環境

- 傾きセンサーと加速度センサーがあるスマホ（iPhone / Android）
- iPhoneでは「はじめる」を押したときに出るダイアログで、モーションセンサーの使用を「許可」してください。
- 画面の回転はロックしておくと安定します。

PCではタイトル画面の「PCで試す」から遊べます。ドラッグで傾け、スペースキーで1歩進みます。

## 仕組み

`index.html` 1ファイルだけで動いています。外部のライブラリは使っていません。

- **傾き**：`DeviceOrientationEvent` で取得します。歩くときの細かい揺れは平滑化し、小さな傾きは無視します。
- **歩数**：`DeviceMotionEvent` の加速度から、上下の揺れのピークを1歩として数えます。
- **物理**：ボールは転がり、食器は摩擦で止まります。水面・積み上げたもの・猫の眠りは、傾きと揺さぶりにばねのように遅れて反応する共通のモデルで動いています。

難しさは `index.html` のスクリプト冒頭にある `SETS` の値（こぼれる・倒れる傾き `thr` など）で、歩数検出の感度は `STEP_HI` で調整できます。

## 注意

- センサーはHTTPSのページでしか動きません。ローカルでファイルを直接開いた場合は「PCで試す」だけが使えます。
- 歩数は加速度から推定しているので、数歩ずれることがあります。その場でスマホを上下に振っても歩数が増えます。
- 歩きながら遊ぶときは、周りや足元に気をつけてください。
