# キャットデレ（試作版）

人が苦手な保護猫を1ヶ月預かり、根気強くお世話して人に慣れさせるシミュレーションゲームです。ブラウザだけで遊べます（スマホ対応）。

## 遊び方

1. 「新しく預かる」を押すと、毛色と性格がランダムに決まった猫がやってきます。名前を付けて預かります。
2. 1日にできるお世話は1回だけです。猫の居場所や様子を見て、行動を選びます。
3. 夜に飼育日記が書かれます。猫の好き嫌いのヒントが混ざっています。
4. 30日目の夜に、どれだけ心を開いたかでエンディングが決まります（5種類）。

信頼度は画面に出ません。猫の居場所（ソファの下 → カーテンの陰 → ラグ → すぐそば → 膝の上）で距離がわかります。
いきなり距離を詰めると「シャー！」や猫パンチをされて、数日警戒されます。

## 調整用

- URLの末尾に `#debug` を付けると、信頼度・警戒・機嫌・性格・成功率が画面下に表示されます。
- 数値は `index.html` の `// ==LOGIC==` から `// ==/LOGIC==` までにまとまっています（行動ごとの `req`＝必要信頼度、`gain`＝上昇量、性格ごとの `prefs`＝好き嫌い）。
- 進行は1日ごとにブラウザ（localStorage）へ自動保存されます。
